# National-Cybercrime-2017-2020

## 📌 Project Overview
This project analyzes **cybercrime data in India from 2017 to 2020** to identify crime trends, high-crime states, and major cybercrime motives.

## 🛠️ Tools & Technology Used
- **Python (Pandas)** – Data cleaning
- **AWS S3** – Data storage
- **Snowflake** – Data processing and SQL analysis
- **Power BI** – Data visualization and dashboard

## 🔄 Project Workflow
`CSV Dataset → Pandas → AWS S3 → Snowflake → SQL Analysis → Power BI`

## 📊 Key Analysis
- Year-wise cybercrime trends
- Highest-crime State/UT each year
- Top 5 States/UTs by total crimes
- Major cybercrime trends each year 
- State-wise crime comparison
- Year-over-year changes
- Crime category distribution

## 📁 Dataset
The dataset contains State/UT-wise cybercrime information for **2017–2020**. Unnecessary columns, empty cells and empty rows were removed, spelling issues are corrected and the data was cleaned before analysis.

## 🎯 Objective
To understand cybercrime patterns in India and present meaningful insights through **SQL analysis and an interactive Power BI dashboard**.
