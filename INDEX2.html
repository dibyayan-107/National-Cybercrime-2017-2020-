PROJECT REPORT

Project Introduction

The Cyber Crime Analysis Dashboard is a data analytics project for cyber crime records from 2017–2020. Its purpose is to turn structured records into meaningful insights through data cleaning, descriptive analysis and interactive visualization. The supplied dataset contains 145 records and 25 fields, including Cyber_Crime_ID, Category, State/UT, Year, Total and numerical motive/category fields.

PROJECT REPORT

Aim & Objectives

Aim: To build a descriptive Cyber Crime Analysis Dashboard for 2017–2020 that identifies major trends, geographic concentration and dominant cyber crime motives using the supplied dataset. Objectives include importing and inspecting the dataset; checking data quality, missing values and duplicates; analysing year-wise totals; comparing States and Union Territories; identifying prominent motives/categories; creating dashboard-ready measures; and presenting findings clearly.

PROJECT REPORT

Data Cleaning & Preparation

The supplied CSV was inspected before analysis. The report records 145 rows and 25 columns, 38 distinct State/UT values, and the four years 2017–2020. Missing cells and duplicate rows were checked; Cyber_Crime_ID is the unique identifier. Numeric fields were prepared for aggregation and column labels were standardized by removing accidental leading/trailing spaces while retaining original values. Total was grouped by Year, State/UT and Category, while motive fields were summed separately.

PROJECT REPORT

Methodology & Tools

The workflow is: CSV source → import into Python/Pandas and Power BI → validation → transformation → aggregation using SUM/GROUP BY concepts → visualization → interactive filtering → interpretation → reporting. Python is used for inspection, validation, aggregation and preparation; Pandas for loading/grouping/calculating totals; SQL concepts for GROUP BY, SUM, ORDER BY and filtering; Microsoft Power BI for interactive charts, cards, tables and slicers; Excel/CSV for structured data handling.

PROJECT REPORT

Dashboard Analysis

The project analyses year-wise cyber crime growth, State/UT distribution, motive/category composition, State versus Union Territory contribution, and leading-State trends. Visuals include KPI cards, line charts, horizontal bar charts, tables, map visuals and slicers. Year, State/UT and Category can be used as filters in the dashboard.

PROJECT REPORT

Conclusion & Future Scope

Recorded totals increase from 21,796 in 2017 to 50,035 in 2020. Uttar Pradesh has the highest aggregated State/UT total at 33,764, followed by Karnataka (31,774) and Maharashtra (17,578). Fraud is the largest motive field at 84,297. The report proposes richer geographic analysis, monthly/quarterly time series, predictive analytics when sufficient historical data is available, advanced Power BI features, automated refresh and additional verified attributes. The project remains a descriptive academic demonstration rather than an official real-time crime intelligence system.
